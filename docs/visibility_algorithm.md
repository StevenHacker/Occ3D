# 3D标注框可见性计算算法

## 1. 概述

本算法用于量化评估3D标注框在点云中的可见性程度，输出范围为 **[0, 1]** 的可见性分数。

### 1.1 应用场景

- 自动驾驶数据标注质量评估
- 遮挡目标过滤与分级
- 标注框可信度评分

### 1.2 核心思想

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   在标注框表面采样 → 检测射线是否被遮挡 → 统计可见比例          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## 2. 算法原理

### 2.1 为什么不检测框内已有点？

```
【错误思路】
检测框内已有的点云是否被遮挡

【问题】
框内存在点 = 激光雷达射线到达了该位置 = 必然未被遮挡

这是一个逻辑悖论：已经被探测到的点，不可能是被遮挡的。
```

### 2.2 正确方法：表面采样

在标注框的**表面**均匀采样虚拟点，检测从传感器到这些采样点的射线是否被其他物体遮挡。

```
                    传感器 ●
                          /|\
                         / | \
                        /  |  \
                       /   |   \
                      ↓    ↓    ↓
                     ✓    ✗    ✓     ← 表面采样点
                    ┌─────────────┐
                    │             │
                    │   标注框    │   ✗ = 被其他点云遮挡
                    │             │   ✓ = 可见（射线畅通）
                    └─────────────┘

                可见性 = 可见点数 / 总采样点数 = 2/3 ≈ 0.67
```

## 3. 算法流程

### 3.1 整体流程图

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   输入数据   │    │  可见面判断  │    │  表面采样    │    │  射线遮挡    │
│              │───▶│              │───▶│              │───▶│  检测        │
│ · 标注框     │    │ 确定朝向     │    │ 按面积分配   │    │              │
│ · 点云       │    │ 传感器的面   │    │ 采样点数     │    │ 逐点检测     │
│ · 传感器位置 │    │              │    │              │    │              │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
                                                                    │
                    ┌──────────────┐    ┌──────────────┐            │
                    │   输出结果   │    │  统计计算    │◀───────────┘
                    │              │◀───│              │
                    │ · 可见性分数 │    │ 可见点/总点  │
                    │ · 状态分类   │    │              │
                    └──────────────┘    └──────────────┘
```

### 3.2 详细步骤

#### 步骤1: 可见面判断

只有**朝向传感器的面**才能被观测到，背向传感器的面永远不可见。

```
                传感器位置
                    ●
                   /
                  /  可见区域
                 /
    ┌───────────────────────┐
    │         顶面 ✓        │   传感器在bbox的右后上方
    │    ┌─────────────┐    │   
    │    │             │    │   可见面:
    │    │    后面 ✓   │    │   · 后面 (-x)  ✓
    │    │             │    │   · 右侧 (-y)  ✓
    │    └─────────────┘    │   · 顶面 (+z)  ✓
    │         右侧 ✓        │
    └───────────────────────┘   不可见面:
          ╳ 前面              · 前面 (+x)  ✗
          ╳ 左侧              · 左侧 (+y)  ✗
          ╳ 底面              · 底面 (-z)  ✗
```

**判断公式：**

设传感器在bbox局部坐标系中的位置为 $(s_x, s_y, s_z)$：

| 面 | 可见条件 |
|----|----------|
| +x (前) | $s_x > 0$ |
| -x (后) | $s_x < 0$ |
| +y (左) | $s_y > 0$ |
| -y (右) | $s_y < 0$ |
| +z (顶) | $s_z > 0$ |
| -z (底) | $s_z < 0$（通常排除） |

#### 步骤2: 面积自适应采样

不同面的面积不同，应按面积比例分配采样点数，保证采样密度一致。

```
【车辆尺寸示例】4.5m × 2m × 1.5m (长×宽×高)

┌─────┐     ┌─────────────────┐     ┌─────────────────────────┐
│ · · │     │ · · · · · · · · │     │ · · · · · · · · · · · · │
│ · · │     │ · · · · · · · · │     │ · · · · · · · · · · · · │
│ · · │     │ · · · · · · · · │     │ · · · · · · · · · · · · │
│ · · │     │ · · · · · · · · │     │ · · · · · · · · · · · · │
└─────┘     └─────────────────┘     └─────────────────────────┘
 后面            右侧面                     顶面
 3.0 m²         6.75 m²                   9.0 m²
 12个点          27个点                    36个点

采样密度 ≈ 0.25 m²/点 (一致)
```

**面积计算：**

| 面 | 面积公式 |
|----|----------|
| ±x (前后) | $2W \times 2H$ |
| ±y (左右) | $2L \times 2H$ |
| ±z (顶底) | $2L \times 2W$ |

**采样数分配：**

$$n_i = N_{total} \times \frac{A_i}{\sum_{j \in visible} A_j}$$

其中 $N_{total}$ 为总采样数，$A_i$ 为第 $i$ 个可见面的面积。

#### 步骤3: 宽高比自适应网格

对于长条形的面（如车辆侧面），采用与宽高比匹配的网格。

```
【侧面 4.5m × 1.5m，宽高比 3:1】

错误：5×5网格（正方形）        正确：6×3网格（匹配比例）
┌─────────────────────────┐   ┌─────────────────────────┐
│ ·   ·   ·   ·   ·       │   │ ·   ·   ·   ·   ·   ·   │
│ ·   ·   ·   ·   ·       │   │ ·   ·   ·   ·   ·   ·   │
│ ·   ·   ·   ·   ·       │   │ ·   ·   ·   ·   ·   ·   │
│ ·   ·   ·   ·   ·       │   └─────────────────────────┘
│ ·   ·   ·   ·   ·       │         均匀分布 ✓
└─────────────────────────┘
    横向稀疏，纵向密集 ✗
```

**网格计算：**

设目标采样数为 $n$，面的两个维度分别为 $d_1, d_2$：

$$n_1 = \sqrt{n \times \frac{d_1}{d_2}}, \quad n_2 = \sqrt{n \times \frac{d_2}{d_1}}$$

#### 步骤4: 射线遮挡检测

对每个采样点，检测从传感器到该点的射线是否被其他点云遮挡。

```
传感器 ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━▶ 采样点
         ↑              ↑
         │              │
      遮挡检测区域    目标点附近
      (排除两端)      (不检测)
         
         ·  ← 如果有点云在射线"锥体"内，判定为遮挡
```

**角度阈值（自适应射线宽度）：**

由于点云的稀疏性，不可能有两点完全在同一直线上。使用角度阈值定义射线的"宽度"：

$$threshold = d \times \tan(\theta_{angle})$$

其中 $d$ 为点到传感器的距离，$\theta_{angle}$ 为角度阈值（默认0.5°）。

```
传感器 ●
        \
         \  角度阈值 θ
          \________________
           \              /
            \   近处窄   /
             \          /
              \________/
               \      /
                \远处/
                 \宽/
                  \/

近处 (10m): threshold ≈ 0.09m
远处 (50m): threshold ≈ 0.44m
```

这种设计符合激光雷达"近密远疏"的特性。

**最少遮挡点数 (min_blockers)：**

为避免单个噪声点造成误判，要求至少 $k$ 个点在射线锥体内才判定为遮挡（默认 $k=3$）。

---

## 4. 数学公式汇总

### 4.1 可见性计算

$$V = \frac{N_{visible}}{N_{total}} = \frac{N_{total} - N_{blocked}}{N_{total}}$$

### 4.2 旋转矩阵 (ZYX顺序)

$$R = R_z(\phi) \cdot R_y(\theta) \cdot R_x(\psi)$$

其中 $\phi$ 为偏航角，$\theta$ 为俯仰角，$\psi$ 为横滚角。

### 4.3 射线遮挡判定

设传感器位置为 $\mathbf{s}$，采样点为 $\mathbf{t}$，场景点为 $\mathbf{p}$：

1. 射线方向：$\mathbf{d} = \frac{\mathbf{t} - \mathbf{s}}{|\mathbf{t} - \mathbf{s}|}$

2. 点在射线上的投影：$proj = (\mathbf{p} - \mathbf{s}) \cdot \mathbf{d}$

3. 点到射线的垂直距离：$dist_\perp = |(\mathbf{p} - \mathbf{s}) - proj \cdot \mathbf{d}|$

4. 动态阈值：$thresh = proj \times \tan(\theta_{angle})$

5. 遮挡判定：若 $dist_\perp < thresh$ 且满足最少点数要求，则被遮挡

---

## 5. 状态分类

| 可见性分数 | 状态 | 含义 |
|-----------|------|------|
| ≥ 0.70 | VISIBLE | 大部分可见，标注可信 |
| 0.30 ~ 0.70 | PARTIAL | 部分可见，需谨慎使用 |
| 0.05 ~ 0.30 | OCCLUDED | 大部分被遮挡 |
| < 0.05 | BLOCKED | 几乎完全不可见 |

---

## 6. 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `total_samples` | 80 | 总采样点数，按面积分配到各可见面 |
| `angle_thresh_deg` | 0.5° | 射线角度阈值，控制射线"宽度" |
| `min_blockers` | 3 | 最少遮挡点数，防止噪声误判 |
| `max_scene_points` | 15000 | 场景点云最大采样数，控制计算量 |
| `exclude_bottom` | True | 是否排除底面（车辆底面通常不可见） |
